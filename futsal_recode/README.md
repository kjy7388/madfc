# Mad FC 기록 페이지 작업 메모

이 폴더는 Mad FC 경기 기록의 기준 자료를 보관하는 위치입니다.

- `mad-fc-season.json`: 선수, 경기, 쿼터별 점수, 선수별 스탯 원본 데이터
- `20260905.png`: 사용자가 전달한 엑셀 캡처 이미지
- `경기 득실.xlsx`: 기존 엑셀 기록 파일
- `선수 정보.png`: 선수 정보 참고 이미지

React 개발 서버는 `my-app/src` 아래의 화면 파일을 읽어 `localhost:3000`에 표시합니다.
앞으로 새 경기 기록을 주시면 이 폴더의 데이터 구조를 기준으로 페이지 내용을 업데이트하면 됩니다.
